# TUN Systemic Design
## Manifesto v0.1

### Designing Intelligence Around Humanity

AI is changing the nature of software.

For decades, we designed systems that waited for humans to operate them.

We designed screens.  
We designed menus.  
We designed workflows.  
We designed applications.

Now we are designing systems that can understand, generate, reason, recommend, remember, collaborate, and act.

The interface is no longer the system.

**Intelligence is becoming part of the system.**

This requires a new design discipline.

We call it:

# TUN Systemic Design

## 01 — Start With Human Intent

Every intelligent system should begin with a human purpose.

Not a screen.  
Not a feature.  
Not a model.  
Not a prompt.

**Intent.**

What is the person trying to accomplish?

AI should translate human intent into useful outcomes without forcing people to understand the complexity underneath.

> **Human Intent → Machine Intelligence → Meaningful Outcome**

## 02 — Design the System, Not the Screen

An AI product is more than an interface.

It is a system of:

**Humans  
AI Models  
Agents  
Memory  
Context  
Data  
Tools  
Rules  
Actions  
Environments  
Outcomes**

Good AI design requires understanding how these elements interact.

A beautiful interface over a poorly designed intelligence system is still a poorly designed product.

**Design relationships, not just components.**

## 03 — Intelligence Should Simplify

AI systems may be extraordinarily complex internally.

The human experience should not be.

More intelligence should create less friction, fewer unnecessary decisions, less navigation, less repetition, and less cognitive burden.

> **Complex intelligence. Simple experience.**

## 04 — Humans Direct. AI Assists.

AI can generate.  
AI can analyze.  
AI can recommend.  
AI can coordinate.  
AI can execute.  
AI can increasingly operate autonomously.

But autonomy should exist within understandable boundaries.

Humans should be able to determine:

**the goal,  
the authority,  
the boundaries,  
the exceptions,  
and the ability to intervene.**

The future is neither human-only nor AI-only.

It is **Human + AI**.

## 05 — Make Agency Visible

Users should know:

- Who is acting?
- What is happening?
- Why is an action being proposed?
- What authority has been delegated?
- What has already happened?
- What can still be changed?

Invisible intelligence creates uncertainty.

Visible agency creates understanding.

## 06 — Design for Appropriate Trust

AI should not pretend to know what it does not know.

Confidence should not be manufactured through visual design.

When information is uncertain, incomplete, inferred, generated, or contested, the experience should communicate what matters to the user.

Trust should come from:

**clarity, evidence, consistency, control, and accountability.**

Not from the appearance of certainty.

## 07 — Permission Before Power

The more consequential an AI action becomes, the clearer its authority should be.

Reading information is different from changing information.

Drafting an email is different from sending it.

Recommending a payment is different from making one.

Analyzing a decision is different from executing it.

TUN therefore treats authority as a designed property of the system.

> **Capability does not automatically imply permission.**

## 08 — Make Important Actions Reversible

Intelligent systems will make mistakes.

Humans will change their minds.

Context will change.

Whenever technically possible, important actions should be:

**inspectable, interruptible, correctable, recoverable, or reversible.**

The ability to recover is part of good design.

## 09 — Memory Must Be Understandable

AI systems increasingly remember.

Memory can make products dramatically more useful.

It can also create confusion when people do not understand what the system knows or why it behaves differently.

Users should have meaningful visibility and control over persistent context where appropriate.

Memory should serve the human.

**The human should not serve the memory system.**

## 10 — Design Agents as Participants

Agents are becoming a new element of digital systems.

An agent may observe, research, reason, plan, communicate, use tools, coordinate other agents, and execute tasks.

Agents therefore require design.

Every meaningful agent should have understandable:

- Identity
- Purpose
- Capability
- Authority
- Context
- State
- History
- Accountability

An agent should never be merely an invisible process when its actions materially affect the human.

## 11 — Design for Collaboration

The future interface may not be one human interacting with one application.

It may be:

**Human ↔ Agent**  
**Human ↔ Multiple Agents**  
**Agent ↔ Agent**  
**Agent ↔ Tools**  
**Agent ↔ Organizations**  
**Human ↔ AI ↔ Human**

Systemic Design must account for these relationships.

The fundamental unit of design therefore moves from the **screen** toward the **interaction between intelligent actors**.

## 12 — Calm Is a Feature

Intelligent systems can produce enormous amounts of information.

That does not mean they should display it.

A good AI product knows when to speak, summarize, ask, recommend, act, wait, and remain silent.

Attention is finite.

> **Intelligence should protect human attention.**

# The TUN Interaction Model

AI interactions can be understood through five fundamental states:

```text
ASK → THINK → PROPOSE → ACT → LEARN
```

For consequential actions:

```text
ASK → THINK → PROPOSE → APPROVE → ACT → VERIFY → LEARN
```

The system should expose only as much complexity as the human needs to remain informed and in control.

# The TUN Principles

We design AI systems to be:

### TRANSPARENT
Make important AI behavior understandable.

### USER SOVEREIGN
Preserve meaningful human authority.

### NATURAL
Allow humans to communicate intent naturally.

### SYSTEMIC
Design relationships across the entire intelligence system.

### ADAPTIVE
Respond intelligently to context.

### REVERSIBLE
Enable correction and recovery.

### COMPOSABLE
Allow humans, agents, models, tools and data to work together.

### CALM
Reduce cognitive burden.

# From Interface to Intelligence

The history of digital design can be seen as a progression:

```text
Command Line
↓
Graphical Interface
↓
Web
↓
Mobile
↓
Conversational Interface
↓
Agentic Interface
↓
Systemic Intelligence
```

At each transition, designers had to reconsider how humans interact with machines.

AI requires another reconsideration.

The future product may contain fewer screens but more intelligence.

Fewer menus but more intent.

Fewer workflows but more delegation.

Fewer clicks but more outcomes.

# From UX to IX

Traditional product design focuses heavily on:

**UX — User Experience**

AI-native products require an additional discipline:

# IX — Intelligence Experience

IX asks:

How does intelligence present itself?

How does it communicate uncertainty?

How does it request authority?

How does it explain actions?

How does it collaborate?

How does it remember?

How does it recover?

How does it know when not to act?

TUN Systemic Design brings **UX + IX + System Design** together.

# A Design System for Humans and Machines

TUN should not exist only as documentation that designers read.

It should eventually become machine-readable.

A designer should be able to use TUN.

A developer should be able to implement TUN.

An AI coding agent should be able to interpret TUN.

An autonomous agent should be able to operate according to TUN interaction rules.

A product should be able to declare:

**TUN-compliant.**

The design system therefore becomes both:

> **A language for designing intelligence**

and

> **A protocol for how intelligence interacts with humanity.**

# Our Design Philosophy

## Simplicity with Boldness.

Remove what does not contribute to understanding.

## Consistency with Conciseness.

Create patterns that remain recognizable across intelligent experiences.

## Clarity with Confidence.

Communicate clearly without pretending that uncertainty does not exist.

# The TUN Promise

We will not design AI merely to appear intelligent.

We will design AI to be **useful**.

We will not hide complexity merely to create an illusion of simplicity.

We will organize complexity so humans can **understand and control what matters**.

We will not measure intelligence only by what a machine can do.

We will also measure it by how well that intelligence works with people.

We will not design humans out of intelligent systems.

We will design better relationships between humans and machines.
